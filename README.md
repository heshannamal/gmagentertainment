# G-MAGe Entertainment — Cinematic Champagne Gold Edition

Complete responsive static website for G-MAGe Entertainment.

## Pages
Home (`index.html`), About, Events, Santhana Nagare, Atheethawarjana 2026, Gallery, Tickets, Contact.

## Identity and images
* Original uploaded event, company and decoration logos are preserved as separate image assets. They are placed over backgrounds by HTML and CSS, not redrawn.
* The founder portrait is the exact uploaded photo.
* Photographic concert backgrounds are concept imagery, not evidence of actual events.

## Deployment
Extract ZIP and upload **the contents** to your domain's Namecheap document root (for example, `public_html/`).
For cPanel Git deployment edit `.cpanel.yml` if your document root differs.

## Important
The ticket booking is a WhatsApp/email inquiry experience with demonstration prices; it does not charge cards or generate confirmed tickets.
Update provisional dates, venue, prices and event details before publishing. Facebook links are provided as supplied by the client.

## Editing
Styles: `css/style.css` · interactions: `js/site.js` · images: `assets/`. All page text is in the corresponding HTML files.
